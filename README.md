## About me

I'm a **Full-Stack Developer** with hands-on experience since **2021**, working across formal roles, independent client work, and self-directed projects.

My main stack is **React, TypeScript, Next.js and Go**, and I enjoy building products end-to-end: UI, APIs, authentication, databases, deployment, and the details that make software actually useful.

A few things I've shipped:

- Built **Meembr**, a SaaS gym-management platform in production and used daily by a paying client.
- Reduced contract creation time from **25 minutes to under 5 minutes** in a real internal system.
- Built software for car rental, real estate, restaurants, local job discovery, and internal business operations.
- Worked with both frontend and backend stacks, including React, Angular, Go, Node.js, PostgreSQL, MongoDB, Supabase and Firebase.
